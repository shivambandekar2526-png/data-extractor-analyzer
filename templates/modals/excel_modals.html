Excel Keyboard & Grid Guide

Work with the result ledger just like Microsoft Excel or Google Sheets

Navigation & Selection

  • Click Select cell
  • ↑ ↓ ← → Move cell selection
  • Tab Move to right cell
  • Shift + Tab Move to left cell
  • Enter Move to cell below
  • Shift + Enter Move to cell above

Editing & Operations

  • Double Click or F2 Edit cell
  • Type Any Key Start typing to edit
  • Esc Cancel cell edit
  • Del / Backspace Clear cell value
  • Ctrl + Z Undo table change
  • Ctrl + Y Redo table change
  • Ctrl + F Find & Replace
  • Ctrl + S Save to Server
💡 Right-Click Menu: Right-click on any row or cell to quickly insert rows above/below, duplicate rows, delete rows, or add/delete columns.
